## 📋 Vue d'ensemble

Cet outil PowerShell analyse votre environnement Microsoft 365 pour fournir des informations précises de dimensionnement pour la planification de sauvegarde et de récupération avec **HYCU**. Il génère un rapport HTML professionnel avec des statistiques d'utilisation pour Exchange Online, OneDrive for Business et SharePoint Online.

### 🎯 Objectifs

- **Évaluer** l'utilisation actuelle de votre environnement M365
- **Calculer** les besoins de stockage pour les sauvegardes HYCU
- **Prévoir** la croissance annuelle des données
- **Planifier** le dimensionnement de votre solution HYCU

---

## 📋 Prérequis

### 🔧 Configuration système requise

| Composant | Requis |
|-----------|--------|
| **Système d'exploitation** | Windows 10/11, Windows Server 2016+ |
| **PowerShell** | Version 5.1 ou supérieure |
| **Modules PowerShell** | Microsoft.Graph.Reports<br/>ExchangeOnlineManagement |
| **Connectivité** | Accès Internet pour Microsoft 365 |

### 👤 Permissions requises

#### Permissions Microsoft Graph API
- `Reports.Read.All` - **Requis**
- `Group.Read.All` - Optionnel (pour filtrage par groupe)
- `GroupMember.Read.All` - Optionnel (pour filtrage par groupe)
- `User.Read.All` - Optionnel (pour filtrage par groupe)

#### Rôles administratifs
- **Reports Reader** - Minimum requis
- **Global Reader** - Recommandé pour accès complet
- **Exchange Administrator** - Requis si analyse des boîtes d'archivage

## 🚀 Installation

### Étape 1 : Installer les modules PowerShell

Ouvrez PowerShell en tant qu'administrateur et exécutez :

```powershell
# Installer le module Microsoft Graph Reports
Install-Module Microsoft.Graph.Reports -Scope CurrentUser -Force

# Installer le module Exchange Online Management
Install-Module ExchangeOnlineManagement -Scope CurrentUser -Force

# Vérifier l'installation
Get-Module -ListAvailable -Name Microsoft.Graph.Reports, ExchangeOnlineManagement
```

### Étape 2 : Télécharger le script

Téléchargez le fichier `Get-M365SizingInfo-HYCU.ps1` dans un répertoire de votre choix.

### Étape 3 : Configurer la politique d'exécution (si nécessaire)

```powershell
# Vérifier la politique actuelle
Get-ExecutionPolicy

# Si "Restricted", modifier la politique
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
```

## 💻 Utilisation

### 📌 Syntaxe de base

```powershell
.\Get-M365SizingInfo-HYCU.ps1 [-AzureAdGroupName <string>] [-SkipArchiveMailbox <bool>] [-EnableDebug <bool>] [-OutputObject]
```

### 🎯 Exemples d'utilisation

#### Exemple 1 : Analyse complète de l'environnement

```powershell
.\Get-M365SizingInfo-HYCU.ps1
```

**Résultat** : Analyse tous les utilisateurs et génère le rapport complet.

---

#### Exemple 2 : Analyse d'un groupe spécifique

```powershell
.\Get-M365SizingInfo-HYCU.ps1 -AzureAdGroupName "Département Marketing"
```

**Résultat** : Analyse uniquement les membres du groupe "Département Marketing".

---

#### Exemple 3 : Inclure les boîtes d'archivage

```powershell
.\Get-M365SizingInfo-HYCU.ps1 -SkipArchiveMailbox $false
```

**Résultat** : Inclut l'analyse des boîtes aux lettres d'archivage (peut être long).

---

#### Exemple 4 : Mode débogage

```powershell
.\Get-M365SizingInfo-HYCU.ps1 -EnableDebug $true
```

**Résultat** : Affiche des logs détaillés pour le dépannage.

---

#### Exemple 5 : Export des données en objet PowerShell

```powershell
$sizingData = .\Get-M365SizingInfo-HYCU.ps1 -OutputObject
$sizingData.Exchange
$sizingData.OneDrive
$sizingData.SharePoint
```

**Résultat** : Retourne les données sous forme d'objet pour traitement ultérieur.

---

### ⚙️ Paramètres détaillés

| Paramètre | Type | Défaut | Description |
|-----------|------|--------|-------------|
| `-AzureAdGroupName` | String | - | Nom du groupe Azure AD pour filtrer l'analyse |
| `-SkipArchiveMailbox` | Boolean | `$true` | Si `$true`, ignore les boîtes d'archivage |
| `-EnableDebug` | Boolean | `$false` | Active les logs de débogage détaillés |

## 🛠️ Dépannage

### ❌ Erreurs courantes

#### Erreur : "Module not found"

```
Required module not found: Microsoft.Graph.Reports
```

**Solution** :
```powershell
Install-Module Microsoft.Graph.Reports -Scope CurrentUser -Force
```

---

#### Erreur : "Forbidden (Forbidden)"

```
The user account used for authentication must have permissions covered by Reports Reader admin role.
```

**Solution** :
- Vérifiez que le compte a le rôle **Reports Reader** dans Azure AD
- Contactez votre administrateur Microsoft 365

---

#### Erreur : "Failed to setup session"

```
ERROR - Failed to setup session after multiple tries
```

**Solution** :
- Vérifiez votre connexion Internet
- Vérifiez les identifiants Microsoft 365
- Désactivez temporairement le VPN si applicable
- Réessayez dans 15-30 minutes (limite de débit API)

---

#### Avertissement : "Could not retrieve data"

```
Warning: Could not retrieve Exchange/OneDrive/SharePoint data
```

**Solution** :
- Vérifiez les permissions API
- Vérifiez que les services sont activés dans votre tenant
- Consultez les logs avec `-EnableDebug $true`

### 📝 Activer le mode débogage

Pour des informations détaillées lors de l'exécution :

```powershell
.\Get-M365SizingInfo-HYCU.ps1 -EnableDebug $true 2>&1 | Tee-Object -FilePath "debug.log"
```

Cela créera un fichier `debug.log` avec tous les détails d'exécution.

## 📈 Calcul de la croissance

### Méthodologie

Le script calcule la croissance annuelle par projection composée (type CAGR)
entre le premier et le dernier point de données de la période :

1. **Collecte** des données de stockage (jusqu'à 180 jours, 1 point/jour)
2. **Extrémités** : premier (`Premier`) et dernier (`Dernier`) jour avec usage
3. **Durée** : `Jours = nombre de points − 1`
4. **Annualisation** : `Croissance% = ((Dernier / Premier) ^ (365 / Jours) − 1) × 100`

### Formule

```
Croissance Annuelle = ((Dernier / Premier) ^ (365 / Jours) - 1) × 100
```

**Note** : Cette estimation peut varier selon les habitudes d'utilisation et
peut être négative si le stockage a diminué sur la période.
